# Kotoba 제품 요구사항 (v0.1)

## 1. 배경
한국어 화자가 일본어를 공부한다. 목적은 한자를 무조건 통째로 쓰면서 암기하는 것이 아니라 **한자의 대표 의미 → 연결된 단어 읽기/뜻 → 예문 → 능동 회상/SRS** 흐름을 만드는 것이다. 각자 다른 JLPT 급수를 학습할 수 있다.

## 2. 대상 기기
- Galaxy: Android Chrome, iPhone: iOS Safari.
- 설치: 브라우저에서 '홈 화면에 추가'. 초기 버전은 PWA이며 네이티브 앱/앱스토어 배포는 미포함.
- 360px부터 세로 화면 최적화. 터치 타겟 44px 이상, 하단 안전영역 처리, 한국어 UI.
- 인터넷 연결 필수. 오프라인 학습/푸시 알림은 추후 개발.

## 3. 사용자 시나리오
1. 이메일과 비밀번호로 가입, 이메일 확인(프로젝트 Auth 설정에 따름), 로그인.
2. 목표 급수(N5/N4/N3/N2)를 선택하거나 변경한다.
3. 한자에서 대표 뜻과 사용되는 단어를 본다; 단어에서 구성 한자와 예문을 본다.
4. 한자 뜻이나 단어 읽기·뜻을 직접 입력하고 채점 결과와 정답을 확인.
5. 별도로 저장되는 읽기/의미 복습 상태에 따라 다음 복습 시점이 달라진다.
6. 각자의 진도, 이번 주 복습량과 오늘 할 일 확인.
7. 기종과 관계없이 동일한 계정 데이터를 볼 수 있다.

## 4. MVP 범위
P0: Auth, profiles, 콘텐츠(kanji/vocabulary/관계), 개인 review_state 및 review_logs, 카드 복습, JLPT 필터, 목표 급수.
P0: 반응형 UI, 홈/학습/복습 탭, PWA manifest.
P1: 오답만 다시 공부, 로딩/네트워크 에러 처리, 읽기 편의성/접근성.
P2: 푸시 알림, 오프라인 캐시·동기화, 실시간 퀴즈 대결, 연속학습 배지, 콘텐츠 관리 도구, 오디오 TTS.

## 5. 구체적 기능 규칙
- 공통 학습 콘텐츠는 사용자가 수정할 수 없음(운영자가 데이터셋 관리).
- 목표 급수는 사용자가 언제든 변경 가능; 과거 복습 기록은 유지.
- '신규'는 review_state가 없는 카드; '복습'은 due_at <= 현재 시각.
- 단어 읽기와 의미는 서로 다른 카드 기록으로 관리.
- 맞음: 간격을 단계적으로 늘림(1/3/7/14/30/60일); 틀림: 낮은 단계부터 다시, 가까운 시점에 복습.
- 당일 복습 횟수와 학습 완료 수는 DB 기록으로 계산; 샘플 더미 통계를 실제 계정에 표시하지 않음.
- 새로운 단어 데이터의 JLPT 분류는 비공식 참고 값임을 명시.

## 6. 성능/보안/품질
- private progress/review logs: auth.uid() === user_id로 RLS 격리.
- 비밀 정보는 환경변수 및 Supabase Auth가 담당. 브라우저에 service_role 금지.
- 비밀번호 자체는 앱 DB에 저장하지 않음.
- 네트워크 에러를 사용자에게 설명하고 재시도 가능하도록 함.

## 7. 릴리즈 목표
M0: 빈 저장소 초기화, 명세, 실행 가능한 앱 껍데기.
M1: Auth + DB 및 예제 학습/복습 + 모바일 UI.
M2: 오답 재학습, PWA 설치 검증.
M3: 데이터셋 확장(검증된 출처), 반복 알고리즘 개선, 실사용 테스트.

## 8. 범위 밖
현 단계에서는 전체 상용한자 2,136자 수록, 공식 JLPT 단어 목록 제공, AI 자동 채점, 결제, 공개 랭킹, 앱스토어 등록을 요구하지 않는다.
